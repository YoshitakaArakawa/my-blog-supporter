# データ辞書

SampleHyperStore: 屋外用品とホーム＆ガーデン用品を扱う架空の米国の小売企業。自社の Web ストア、アプリ、他社のマーケットプレイス、法人取引で販売している。24 テーブル、テーブルごとに1つの CSV で、2023-01-01 から 2025-12-31 までを対象とする。名前、場所、数値はすべて合成したもの。

日本語版は英語版の翻訳で、列名と、区分の値・商品名などの文字列の値を日本語にしている。数値、日付、ID、コードは英語版と同じ。金額は USD。

**Tableau** 列に yes とあるのは、`setup/` が Tableau Cloud にパブリッシュする 12 テーブル。残りの 12 テーブルは CSV だけで提供する。

## web_searches

サイトとアプリの検索: 検索語、結果の数、そのうち訪問者の担当倉庫で在庫があった数、最初にクリックされた結果。

- ファイル: `csv/web_searches.csv`（100,524 行）
- 粒度: 実行したサイト内検索ごとに1行
- 主キー: `検索ID`
- 担当（架空の部門）: デジタルマーケティング

| 列 | 型 | 空 | キー | 説明 |
|---|---|---|---|---|
| `検索ID` | string |  | pk | 検索の識別子（グループ内部）。 |
| `セッションID` | string |  | → web_sessions.セッションID | 検索を実行したセッション。 |
| `検索日時` | datetime |  |  | 検索の日時。 |
| `検索日` | date |  |  | `検索日時`の日付部分。 |
| `検索語` | string |  |  | 検索エンジンが正規化した検索語（小文字化、前後の空白除去）。 |
| `検索入力種別` | string |  |  | 検索語の入力のしかた。値: 手入力、オートコンプリート、結果なし後の候補。 |
| `結果件数` | integer |  |  | 在庫に関係なく、検索語に一致した有効な商品の数。 |
| `在庫あり結果件数` | integer |  |  | `結果件数`のうち、訪問者の担当倉庫で在庫ありまたは残りわずかと表示された商品の数。 |
| `クリック商品ID` | string | あり | → products.商品ID | 結果から最初にクリックされた商品。クリックがなければ空。 |
| `クリック結果順位` | integer | あり |  | `クリック商品ID`の結果一覧での順位（1 から始まる）。 |

## web_sessions

Web・アプリの分析ツールが記録したセッション: いつ、どこから、どのデバイスで、誰が（特定できた場合）、ファネルのどこまで進んだか、そのセッションでどの注文が完了したか（あれば）。

- ファイル: `csv/web_sessions.csv`（455,057 行）
- 粒度: Web またはアプリのセッションごとに1行（直販チャネルのみ。マーケットプレイスと法人の注文にはセッションがない）
- 主キー: `セッションID`
- 担当（架空の部門）: デジタルマーケティング

| 列 | 型 | 空 | キー | 説明 |
|---|---|---|---|---|
| `セッションID` | string |  | pk | 分析ツールが発行したセッションの識別子。 |
| `訪問者ID` | string |  |  | 匿名のデバイス・ブラウザの識別子（Cookie またはアプリのインストール）。グループ内部のキー。1人の訪問者が多くのセッションを持つことがあり、ログイン後は1つの`顧客ID`に対応する。 |
| `顧客ID` | string | あり | → customers.顧客ID | セッション中に特定された顧客。匿名のセッションでは空。 |
| `セッション開始日` | date |  |  | セッション開始日時の日付部分。日次の集計にはこれを使う。 |
| `チャネル` | string |  |  | セッションが属する販売チャネル（`orders`.`チャネル`と共通のコード。ここには直販チャネルだけが現れる）。値: Web、アプリ。 |
| `デバイス種別` | string |  |  | 分析ツールが報告したデバイスの区分。値: デスクトップ、モバイル、タブレット。 |
| `州コード` | string |  |  | 分析ツールが訪問者の IP から推定した米国の州（2文字コード、DC を含む）。 |
| `流入元` | string |  |  | セッションの流入元（分析ツールのラスト・ノンダイレクトクリックのルール）。値: 直接、オーガニック検索、有料検索、有料ソーシャル、オーガニックソーシャル、ディスプレイ、メール、アフィリエイト、リファラル、プッシュ通知。 |
| `キャンペーンID` | string | あり | → campaigns.キャンペーンID | トラッキングパラメータからセッションに割り当てたキャンペーン。オーガニック、直接、リファラルでは空。 |
| `ランディングページ種別` | string |  |  | セッションの最初のページの種類。値: ホーム、カテゴリ、商品、検索、販促、コンテンツ、カート。 |
| `ページビュー数` | integer |  |  | セッションで記録したページビュー・アプリの画面表示の数。 |
| `商品閲覧数` | integer |  |  | セッションで閲覧した商品詳細ページの数。 |
| `在庫切れ商品閲覧数` | integer |  |  | 訪問者のフルフィルメント倉庫で在庫切れと表示された状態で閲覧した商品詳細ページの数。 |
| `カート追加日` | date | あり |  | セッションで最初にカートに追加した日。追加がなければ空。 |
| `カート追加数量` | integer |  |  | セッション中にカートに追加した数量（削除は差し引かない）。 |
| `チェックアウト開始日` | date | あり |  | チェックアウトを始めた日。セッションがチェックアウトに進まなければ空。 |
| `注文ID` | string | あり | → orders.注文ID | このセッションで完了した注文。注文がなければ空。`orders`.`セッションID`と対応する。 |
| `計測注文額` | decimal(12,2) | あり |  | 購入の時点で分析ツールが記録した取引額（割引後の商品額に送料と税を足したもの）。注文がなければ空。外部システムが報告した値（ここでは再計算していない）。 |

## campaign_daily

各プラットフォームが報告した日次の配信とコスト: インプレッション、クリック、メールのファネルの件数、広告費、プラットフォーム自身のコンバージョンとコンバージョン金額。

- ファイル: `csv/campaign_daily.csv`（9,295 行）
- 粒度: 配信のあったキャンペーン × 日ごとに1行
- 主キー: `キャンペーンID`、`レポート日`
- 担当（架空の部門）: マーケティング

| 列 | 型 | 空 | キー | 説明 |
|---|---|---|---|---|
| `キャンペーンID` | string |  | → campaigns.キャンペーンID | キャンペーン。 |
| `レポート日` | date |  |  | プラットフォームのアカウントのタイムゾーンでのレポート日。 |
| `インプレッション数` | integer |  |  | 広告のインプレッション（メールとプッシュでは 0）。 |
| `クリック数` | integer |  |  | プラットフォームが報告したクリック（メールとプッシュではユニーククリック）。 |
| `送信数` | integer | あり |  | 送信したメッセージ（メールとプッシュのみ。それ以外は空）。 |
| `配信数` | integer | あり |  | 配信されたメッセージ（メールとプッシュのみ）。 |
| `開封数` | integer | あり |  | ユニーク開封（メールとプッシュのみ）。 |
| `配信停止数` | integer | あり |  | その送信による配信停止（メールとプッシュのみ）。 |
| `広告費額` | decimal(12,2) |  |  | その日にプラットフォームが請求したコスト（USD）。 |
| `媒体コンバージョン数` | integer |  |  | プラットフォームが`campaigns`.`アトリビューション期間`に従ってキャンペーンに帰属させた購入。クリック・インプレッションの日に計上する。外部システムが報告した値（ここでは再計算していない）。 |
| `媒体コンバージョン額` | decimal(12,2) |  |  | プラットフォームがキャンペーンに帰属させた購入金額（サイトのタグが送る値: 税と送料を含む注文合計）。外部システムが報告した値（ここでは再計算していない）。 |
