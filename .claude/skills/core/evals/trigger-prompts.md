# トリガーテスト

## 起動すべき（should fire）

### テーマを立てる・発散する

- Tableau の AI 機能について記事を書きたい
- 新しいブログのテーマを思いついたので相談したい
- この話、記事になりますか
- 来月の勉強会で何を話すか一緒に考えたい
- この記事の内容で登壇したい
- ai-bi-platform の記事の続きをやろう
- /core ai-bi-platform

### 掘る

- この主張をもっと掘りたい
- なぜこれを書きたいのか、自分でも整理できていない
- コアメッセージを言語化したい
- 聞いた人にどうなってほしいかを整理したい
- 前回の指摘を踏まえてもう一度考え直したい
- /core ai-bi-platform deepen

### 地図

- 全体像を1枚で見たい
- 記事の見取り図を作って
- この構成で書き始めていいか、俯瞰して確認したい
- 章立ての重心が移ったので地図を描き直したい
- /core ai-bi-platform map

## 起動すべきでない（should not fire）

- 記事の構成を一緒に考えたい（→ /blog-write の組む工程）
- 本文を書いてみて（→ /blog-write の書く工程）
- 登壇の流れを組みたい（→ /presentation-write の組む工程）
- スライドの見出しと台詞を考えて（→ /presentation-write の書く工程）
- Google スライドに組んで（→ /presentation-slides）
- この主張の想定反論を出して（→ /review の critique）
- 記事の中に入れる概念図を1枚描いて（→ /illustrate）
- 本文は固まったので、ここから細かく直したい（→ /blog-revise）
- この記事を公開層に反映して（→ /blog-promote）
- この記事の計画、どこが弱いか指摘して（地図は判定しない。叩くのは /review の critique）
- リポジトリの skill 構成を棚卸ししたい（記事づくりではない）
