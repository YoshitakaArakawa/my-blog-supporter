# 見た目の方針

## 方針と、テンプレートでの表し方

| 方針 | 表し方 | 出どころ |
|---|---|---|
| デモの画面は、見出し1行と枠いっぱいの画像にする | 役割「画面」→ レイアウト「見出し1行と画面」（見出しは1行まで） | 著者判断 20261101 |
| 本文のスライドは、見出しの位置を揃える | 本文のレイアウトの見出しは、どれも左上の同じ位置 | 著者の依頼 20261101 |
| 図は Slides の図形に写さず、画像で貼る | `見せる:` に PNG のパスを書く。組上は画像の差し込み | 著者案 20261101 |
| 出典の行は、右下に右揃えで置く | 出典の枠は下端・右揃え | 著者判断 20261101 |
| 図の中の文字も最小文字を守る | illustrate のスライド用の寸法（`slide-figures.md`）で描く | 20261101 に、画像に入れた 18pt 未満の文字が点検から外れたため |
| 表紙・区切り・終わりはネイビーの背景に白い文字、本文は白に近い背景に紺に近い黒の文字。見出しの下の線や縁の帯などの飾りは置かない | 内蔵のテンプレート（navy） | 著者判断 20261108 |
| 書体は Noto Sans JP（変換に困らない普遍的な書体） | テンプレートの `font` | 著者判断 20261108 |
| 背景はふだんテンプレートのまま。話に合わせた背景は、欲しい回だけ差し替える | — | 著者判断 20261108 |
| 画像の枠の左端は見出しの文字の左端に揃える。デモの画面の枠だけは広く取る | 内蔵のテンプレートの `frame` | 著者判断 20261108 |
| スピーカーノートは使わない。使う時は著者が Slides で入れる | 組上でノートに書かず、取り込みでも読まない | 著者判断 20261108 |
| QR の枠は置かない。1回の登壇の例に引っ張られた作りは見直す | 「終わり」の QR の枠を外した。表紙の写真の枠は見直しの候補 | 著者判断 20261108（「QR は考慮不要。テンプレートが1つの例を汎用化できていないかも」） |

## 足し方

- 登壇ごとの判断は、deck.md 冒頭の ℹ️ メモに `著者判断: … （yyyymmdd）` で残す。ここには足さない
- 2回以上の登壇で同じ判断が出たら、ここに足す。表し方（どのレイアウト・どの定義で表すか）と出どころ（日付と、著者判断か著者の依頼か）を添える
- テンプレートの定義で表せる方針は、定義を直して `sync-template.mjs` でテンプレートのデッキに同期する。表せない方針は、組んだ後に Slides で直す
- テーマ（背景や配色）を新しく選ぶ回は、複数の案を HTML の一覧で並べて著者が選ぶ
