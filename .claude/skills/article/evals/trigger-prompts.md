# トリガーテスト

## 起動すべき（should fire）

### テーマを立てる・発散する

- Tableau の AI 機能について記事を書きたい
- 新しいブログのテーマを思いついたので相談したい
- この話、記事になりますか
- ai-bi-platform の記事の続きをやろう
- /article ai-bi-platform

### 掘る

- この主張をもっと掘りたい
- なぜこれを書きたいのか、自分でも整理できていない
- コアメッセージを言語化したい
- 前回の指摘を踏まえてもう一度考え直したい
- /article ai-bi-platform deepen

### 組む

- 記事の構成を一緒に考えたい
- 見出しの順番をどうするか迷っている
- どの話から入るのがいいと思う？

### 書く

- 本文を書いてみて
- ドラフトを起こして
- 導入だけ書き直して
- /article ai-bi-platform write

### 地図

- 全体像を1枚で見たい
- 記事の見取り図を作って
- この構成で書き始めていいか、俯瞰して確認したい
- 章立ての重心が移ったので地図を描き直したい
- /article ai-bi-platform map

## 起動すべきでない（should not fire）

- この主張の想定反論を出して（→ /review の critique）
- outline.md から主張が落ちていないか点検して（→ /review の drift）
- 記事のドラフトを読者視点で読んでみて（→ /review の readers）
- Wix の下書きをレビューして（→ /review の author。取り込みも lens 側）
- 記事の中に入れる概念図を1枚描いて（→ /illustrate）
- 公開したので AI 版と比べて改善案を出して（→ /compare-drafts）
- この記事を公開層に反映して（→ /publish-article）
- X のポストの中身を取ってきて（→ /fetch-page）
- この記事の計画、どこが弱いか指摘して（地図は判定しない。叩くのは /review の critique）
- リポジトリの skill 構成を棚卸ししたい（記事づくりではない）
