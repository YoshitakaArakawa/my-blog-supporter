# スライド用の図の寸法

## 規範

- キャンバスは「置く枠の大きさ（in）× 192」px にする。縦横比が枠と同じなら、Slides は図を枠いっぱいに置き、図の 1px が 0.375pt になる
- 図の中の文字は、主催の最小文字（event.md の `最小文字:`）× 192 / 72 px 以上にする。18pt なら 48px。凡例・軸・注記も例外にしない
- 縦横比を枠に合わせる。違うと、Slides は図を枠の中に縮めて置き（縦か横の長い方が枠に当たる）、そのぶん文字が小さくなる

悪い例: 見出しの下の枠（9.0×3.65in）に、1700×770 の画面から切り出した図を2倍の解像度で貼る。図の 1px が約 0.17pt になり、24px で描いた文字は約 8pt で映る。
良い例: 同じ枠に 1728×701px のキャンバスで描き、いちばん小さい文字を 48px 以上にする。

## 寸法の出し方

リポジトリのルートで次を実行すると、`見せる:` の枠ごとに図の寸法と文字の下限が出る。

```bash
node .claude/skills/presentation-slides/scripts/render-slides.mjs output/{登壇}/deck.md --frames
```

内蔵のテンプレート（navy）で最小 18pt の時の値:

| 置き場（レイアウト） | 枠 | キャンバス |
|---|---|---|
| 見出しと図（出典なし） | 9.0×3.65in | 1728×701px |
| 見出しと図（出典あり） | 9.0×3.15in | 1728×605px |
| 文と図（出典なし） | 5.2×3.65in | 998×701px |
| 文と図（出典あり） | 5.2×3.15in | 998×605px |
| 全面（参考） | 10×5.625in | 1920×1080px |

正本はテンプレートの定義（`template.json` の `frame`）で、上の表は例。定義が変わったら `--frames` の出力に従う。

## ブログの図との違い

- style.md の文字の下限（本文幅 720px への縮小が前提）は使わず、上の下限に置き換える
- 配色・線と形・繰り返し要素・図中のタイトルの扱いは style.md のまま
- 書体は同梱の Zen Kaku Gothic New のまま。スライドの文字は Noto Sans JP だが、図は画像なので混ざってよい
- 出力先と貼り先は呼び出し側の指定に従う（登壇は `output/{登壇}/figures/` と deck.md の `見せる:`）

## 確かめ方

- PNG の幅と高さが、渡された寸法どおりか
- いちばん小さい文字の font-size が、渡された下限以上か（ソースで確かめる）
- 呼び出し側が、deck.md の `見せる:` に図を置いて presentation-slides の一覧（`preview/slides.html`）で見え方を確かめる
