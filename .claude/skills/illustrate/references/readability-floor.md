# Readability Floor（縮小表示に耐える下限）

## 前提

図はブログ本文幅（約 720px）に縮小して表示される。キャンバス幅 1180 の図は約 0.6 倍で見られる。以下の数値はキャンバス幅 1180 換算で、幅が違えば比例させる（例: 幅 1500 なら各値を 1500/1180 倍）。

## 文字サイズ（1180 幅換算）

| 用途 | 下限 |
|---|---|
| 見出し・句（図の主張を担う語） | 24px 以上 |
| 主ラベル（要素名・軸名） | 22px 以上 |
| 補助ラベル・注記・出典 | 18px 以上 |

18px 未満は 0.6 倍で 11px を切り、本文幅では読めない。「小さく添える」表現は、サイズを下げる代わりに色を補助の下限まで落とすか、位置を端に寄せて実現する。

## 文字色のコントラスト（背景に対する WCAG 比）

| 用途 | 下限 |
|---|---|
| 読ませる文字（見出し・主ラベル） | 7:1 以上 |
| 補助文字（注記・軸目盛・出典） | 4.5:1 以上 |
| 意図的に「無い・弱い・過去」を表す文字 | 3:1 以上 |

- 淡色化は上の下限までに留める。3:1 を切る文字は「弱い」ではなく「消えている」。
- 背景が淡色（例 `#fbfbfa`）のとき、`#8a949f` 系のグレーは 3:1 前後で補助文字にも足りない。補助文字は `#5c6570` 程度（約 5:1）まで濃くする。
- 塗りの上に置く文字は、その塗り色に対して比を取る。
- 検算は WCAG のコントラスト比（相対輝度の比）で行う。手計算が面倒なら、明度の近い既知の組み合わせで代替せず、実際に比を出す。

## 縦横比

- 16:9〜4:3 に収める。
- 横長の時系列・段階列（例 1240×336 のような 4:1 弱）は本文幅で文字が潰れる。行を折り返すか、縦積みにする。
- 縦長は 3:4 まで。スクロールを要する図は 2 枚に分ける。

## 最終確認（自己レビューに組み込む）

PNG を 0.6 倍で見ても読めることを確認してから合格にする。方法はどちらか:

- 縮小した PNG を Read して目視する（例: 幅 720px の PNG を別途書き出す、または画像ビューアで 60% 表示）。
- viewBox を 720 幅換算で検算する。`font-size × 720 / viewBox幅` が上表の下限 × 0.6（見出し 14.4px・主ラベル 13.2px・補助 10.8px）以上か。

原寸の PNG が読めても合格にしない。原寸で読める図が本文幅で読めなくなるのが典型の失敗パターン。
