# トリガー回帰テスト（tighten-draft）

fresh session で以下を投げ、起動の有無を確認する。

## 起動すべき

- `/tighten-draft 20260912_example`
- 「draft.md が長すぎるので公開版の密度まで削って」
- 「AI 版が太っている。保険文と多段の論証を落として 7,000 字以下にして」
- 「磨きこみで本文が膨らんだから、もう一度圧縮パスを回して」

## 起動すべきでない

- 「draft.md の主張に反論して」（review の critique）
- 「outline から落ちた主張が無いか点検して」（review の drift）
- 「初見の読者としてこの記事を読んでどう感じるか教えて」（review の readers）
- 「draft_user.md を編集者の目でレビューして」（review の author）
- 「この記事を書き始めたい」（article）
