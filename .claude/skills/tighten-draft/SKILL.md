# ドラフト圧縮

記事ドラフトを、著者の公開記事の密度まで削って上書きする。

出力先は `output/{yyyymmdd}_{テーマ}/`。`output/` を Glob し、`_{テーマ}` で終わるフォルダを採る（テーマに日付プレフィックスが付いていればそのまま使う）。以降 `$OUTPUT_DIR` はこのディレクトリを指す。

このスキルは隔離コンテキスト（`context: fork`）で実行される。会話履歴にはアクセスできないため、対象と基準はすべてファイルから読む。書いた当人は自分の保険文を「必要な補足」と感じて削れないので、別エージェントが「公開版の密度」を基準に削る。メイン会話には**実行サマリのみ**を返す。

## やらないこと

- 主張の追加・言い換えによる補強（足す方向の編集）
- 主張の是非の判断（`review` の `critique`）、前段との整合点検（同 `drift`）
- ヘッジ（「かもしれません」「思います」「気がします」）の削除。文体資産なので残す
- 固有名詞・一次情報・引用原文（3 文まで）の削除

## 手順

### 1. 引数と入力

- テーマ: `$0`
- 対象ファイル名: `$1`

上の2行は起動時に実引数へ置換される。対象ファイル名の欄が空、置換されずに残っている、または `.md` で終わらない場合は既定の `draft.md` を使う。

対象ファイル冒頭の ℹ️ メモに「著者判断」があれば、最初に読む。字数を目標にしない旨があれば、本文字数では削らず、手順2の9を行わない。

読む:
- `$OUTPUT_DIR/{対象ファイル名}`（必須。無ければ「対象が見つからないので、先に `/article` の書く工程を回してください」とサマリで返して終了）
- `$OUTPUT_DIR/core.md`（あれば。**落としてはいけない背骨の最上位**。核の問い・読者・読後に効く文は、保険文に見えても削らない）
- `${CLAUDE_PROJECT_DIR}/.claude/skills/article/references/voice-style.md` の「0. 数値仕様」「1. 実例」「22」「23」
- `$OUTPUT_DIR/outline.md`・`$OUTPUT_DIR/thinking.md`（あれば。**落としてはいけない背骨**の一覧として使う）

圧縮前の指標を取る:

```
node scripts/lint-draft.mjs $OUTPUT_DIR/{対象ファイル名} --no-textlint
```

圧縮前のファイルを `$OUTPUT_DIR/draft_pre-tighten.md` に複製しておく（既にあれば上書き）。

### 2. 削る順序

数値仕様に収まるまで、次の順で削る。各段階で「落とした背骨が無いか」を core/outline/thinking と照合する。

1. **禁止句を含む文**（lint の「禁止句」と voice-style「0.」の一覧）。保険・誠実さの演出（「誤解されたくないので」「念のため」「正直に書くと」「〜は認めます」）は文ごと削る。反論への返しの内容が有用なら ℹ️ メモへ移す
2. **章間の道案内**（「ここまでは〜」「ここから〜」「次は〜の話」）。削って「一方で」「ただし」か接続詞なしで続ける。ただし本筋と余談の境界に置く読者への断り（例: 以下は余談なので、読み飛ばしてもらって大丈夫です）は削らない（cognitive-rhythm.md の例外3）
3. **多段の論証**。1 章は 5 手で畳む。想定反論への救済ロジックは 1 段目（認める）だけ残し、2 段目以降（論破・再反論の先回り）を削る。1 つのアハに対する権限分解・追加引用・英文原文の重ね掛けは、日本語の 1 文対比に圧縮する
4. **結びの定型**。動機の再掲・読者への問い返し・続編予告・宿題開示を削り、「ということで〜でした」または短い割り切りに寄せる。18 文以内
5. **「」の減量**。概念名は初出のみ、一般語は外す。25 個以下
6. **造語の反復**。5 回を超える分は普通の語に言い換える。章題から外す
7. **英語ラベルの日本語化**、英文引用は 3 文まで
8. **3 文以上の段落を分割**する。分割は削除ではない。括弧の補足は独立段落にする。分割で 40 字未満の断片が続かないようにし、1文ずつの短い段落が続く箇所は、同じ論点の段落を1つにまとめる（lint の「段落あたり字数」。まとめるだけで、主張は足さない）
9. それでも 7,000 字を超えるなら、技術詳細・自分の実装手順を余談か外部リンクへ逃がす

削ったもののうち、著者が判断すべきもの（反論への返し・出典の注記・削った技術詳細）は、ドラフト冒頭の ℹ️ 引き継ぎメモ（引用ブロック）に 1 行ずつ追記する。メモが無ければ作る。

### 3. 書き戻しと検算

`$OUTPUT_DIR/{対象ファイル名}` を上書きし、再度 lint を実行する:

```
node scripts/lint-draft.mjs $OUTPUT_DIR/{対象ファイル名} --no-textlint
```

数値仕様の NG が残っていれば手順 2 を繰り返す（最大 3 周）。3 周で収まらない項目は、理由を添えてサマリで返す。

### 4. 実行サマリを返す

メイン会話には以下だけを返す:
- 圧縮前後の指標（本文字数・3 文以上の段落数・「」個数・禁止句数）
- 削った項目の件数（保険文／道案内／論証段／結び／その他）と、ℹ️ メモへ移した件数
- 落とさなかった背骨の確認（core/outline/thinking の主張が全て残っている旨、または落ちた疑いがある主張）
- 収まらなかった NG とその理由

本文の全文は返さない。
