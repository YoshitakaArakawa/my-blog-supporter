主催の規定を、主催の資料（案内の PDF・メール・フォーム）から起こす骨格。事実だけを書き、資料に無いことは `未確認` と書く。スクリプトが読むのは `時間:`・`最小文字:`・`画面比:`・`提出:` の4行なので、`key: value` の形を崩さない。

```markdown
# 場: {イベント名}

場: {イベント名とセッション（番号・日時・会場）}
時間: {自分の持ち時間。例 5分}
形式: {単独 / リレー（人数）/ パネル}
画面比: {16:9}
提出: {Google スライド / PDF / 当日持ち込み}（締切 {yyyymmdd}）
最小文字: {18pt}
余白: {20px}
ノート: {使える / 使えない（画面の複製投影など）}
禁止: {主催のロゴ・キャラクター、Web 記事のスクリーンショット など}
観客: {人数と層。例 30席と立ち見、初めて聞く人が大半}
共同登壇: {人数と、自分の持ち場}
出典: references/{主催の資料のファイル名}

## 補足

{資料にあるほかの条件、未確認の点、講演概要の約束との食い違い}
```

`時間:` は「5分」「20分」「5分30秒」の形で書く。共同登壇なら、全体の枠ではなく自分の持ち時間を書く（全体の枠は `場:` に書く）。
