# サムネイル（カバー画像）

記事のカバー画像を、ブログ共通の型で作る。デザインは毎回選び直さない。決めるのはタイトルの改行位置だけ。

引数: `$ARGUMENTS`（テーマとタイトル。どちらも任意）。対象は `output/{yyyymmdd}_{テーマ}/`（以降 `$OUTPUT_DIR`）。

## スタイル（正本）

公開済みの3記事のカバー画像を実測した値。テンプレート [templates/thumbnail.html](templates/thumbnail.html) はこの表を実装したもので、値を変える時は両方を直す。

| 項目 | 値 |
|---|---|
| キャンバス | 1122×1063 px、PNG |
| 背景 | 白（`#fff`）。枠・図形・ロゴは置かない |
| 文字 | タイトルだけ。上下左右の中央に置き、各行を中央揃えにする |
| 色 | `#595959` |
| 書体 | Meiryo の Bold。Meiryo が無い環境では同梱の Zen Kaku Gothic New Bold に替わる |
| サイズ | 96px。行が収まらない時だけ 64px まで下げる |
| 行間 | 1.25 |
| 改行 | 手で決める（次節）。自動の折り返しはしない |

書体は見た目からの推定で、既存画像の作成に使った書体は確かめていない。Meiryo の有無で字形が変わるので、Windows 以外で作った画像は既存記事と並べて差を確かめる。

## 改行位置の決め方

- 意味の切れ目で切る。助詞は前の行の末尾に付ける（例: `Tableau / ワークブック作成の / 全てを生成AIに / 任せてみた実験`）。
- 1行は全角10字前後まで。スクリプトが行幅を概算し、収まらない見込みなら撮らずに止まる。
- 行数は2〜4行を目安にする。
- 絵文字はタイトルに含まれていればそのまま置く（カラー絵文字で描かれる）。

## 手順

進捗:

- [ ] **タイトルを取る**: 引数に無ければ `$OUTPUT_DIR/draft_user.md` の先頭行、無ければ `draft.md` の先頭行。`[AI下書き]` などの印は外す。タイトルの文言は変えない。
- [ ] **改行位置を決める**: 上の規則で1案を作り、`/` 区切りで著者に示す。著者が改行を指定済みならそのまま使う。
- [ ] **書き出す**: リポジトリルートで次を実行する（1引数が1行）。

  ```bash
  node ${CLAUDE_SKILL_DIR}/scripts/make-thumbnail.mjs $OUTPUT_DIR "行1" "行2" "行3"
  ```

  `images/src/thumbnail.html`（ソース）と `images/thumbnail.png`（成果物）ができる。レンダリングは illustrate の `render-figure.sh` を使い、同梱フォントが読めていなければ撮らずに止まる。
- [ ] **見て確かめる**: PNG を Read し、行の見切れ・余白の偏り・字形の化けがないかを見る。
- [ ] **後始末**: `rm -rf .playwright-cli/`。
- [ ] **著者に返す**: PNG のパスと採った改行を返す。改行を変えたいと言われたら、同じコマンドを行を変えて再実行する（同名で上書き）。

## Wix への設定

カバー画像は著者が Wix の編集画面で設定する（投稿の設定でカバー画像に `images/thumbnail.png` を選ぶ）。`/wix-sync` はカバー画像を扱わない。

## 出力契約

- 成果物は `$OUTPUT_DIR/images/thumbnail.png` の1枚。改訂は上書きし、`_v2` などの版名ファイルを増やさない。
- 型を外す変更（背景色・図形・サブタイトルの追加）はしない。著者が求めた時は、この型の変更として「スタイル」の表とテンプレートを一緒に直す。
